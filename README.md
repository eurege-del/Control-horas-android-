# Control Horas — Android

Primera versión del proyecto Android basado en la hoja de Excel.

Incluye:
- Inicio/final de jornada con un toque.
- Contador de tiempo trabajado.
- Historial diario.
- Resumen semanal y mensual.
- Diseño sencillo en Jetpack Compose.

## Abrir
1. Instala Android Studio en un ordenador.
2. Abre esta carpeta como proyecto.
3. Espera a que Gradle sincronice.
4. Conecta el móvil Android con depuración USB o usa un emulador.
5. Pulsa Run.
